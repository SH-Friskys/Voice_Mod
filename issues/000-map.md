## Destination

A build-ready spec for a custom Windows app that transforms the user's voice live: open-source components where possible, sliders and buttons that act instantly, classic Effects in v1, and an architecture that lets a Voice Converter (AI) be dropped in later without a rewrite. Done when nothing remains to decide before implementation starts.

## Notes

- Domain: real-time audio / DSP on Windows. Vocabulary lives in [CONTEXT.md](../CONTEXT.md); use its terms.
- User is new to audio tech: explain choices in plain language and always give a recommendation.
- Claude will write and implement the code; optimise for what Claude can build and maintain well.
- Standing requirements: **live use** (low latency is non-negotiable); **Windows only** to start; Controls change the sound **without restart**; open-source preferred.
- v1 features fixed by the user: Presets, global hotkeys, Bypass button, Monitoring (toggle, off by default), Noise Suppression (toggle).
- Skills for grilling tickets: `grilling` + `domain-modeling`.
- Tracker: local markdown, see [README.md](README.md).

## Decisions so far

<!-- one line per closed ticket -->

- [Choose the Virtual Microphone driver](001-virtual-mic-driver.md): VB-CABLE, with Voicemeeter as fallback. No signed open-source driver exists. Output device is user-selectable, and render at 48 kHz.
- [Learn how open-source real-time Voice Converters run](004-ai-voice-converters.md): converters add about 50–430 ms and are mostly Python + PyTorch, often in a separate worker process. The seam is a uniform block `process` interface with changeable latency reporting, plus an adapter that hosts converters in or out of process at 48 kHz float32.
- [Survey Windows low-latency audio I/O options](003-windows-audio-io.md): WASAPI low-latency shared mode (about 10 ms for our part) via miniaudio, RtAudio or JUCE. Python is ruled out for the audio path. The app handles clock drift itself and runs at the native 48 kHz.
- [Survey open-source DSP libraries for classic Effects and Noise Suppression](002-dsp-libraries.md): stay permissively licensed (no JUCE, Rubber Band or GPL Faust functions). Signalsmith Stretch for pitch and formant (latency needs tuning), RNNoise for Noise Suppression, Faust `zita_rev1` or `freeverb` for reverb, hand-written robot, echo, EQ and distortion.

## Not yet specified

- **UI layout and look**: what the main window shows and how sliders, Presets and toggles are arranged. Likely a prototype once the Effect list and Effect Chain model settle.
- **Hotkey behaviour inside games**: global hotkey mechanism, conflicts with game keybinds, possible anti-cheat concerns.
- **Preset storage**: file format, where they're saved, whether Presets can be shared or imported.
- **First-run setup and installation**: how the user picks their Input Mic and output device, and is guided to point Discord or games at "CABLE Output". Driver distribution itself is now its own ticket.
- **Device handling**: mic unplugged mid-session, default-device changes, devices not running at 48 kHz. Drift correction between the two devices is required; see [Survey Windows low-latency audio I/O options](003-windows-audio-io.md).
- **Where Noise Suppression and Monitoring sit in the Effect Chain**: before or after Effects, and how Monitoring avoids feedback and echo.
- **Testing and quality approach**: how to verify latency and sound quality before calling v1 done.

## Out of scope

- **Writing our own virtual audio driver**: kernel-driver signing is prohibitive, so we depend on an existing driver (see [Choose the Virtual Microphone driver](001-virtual-mic-driver.md)).
- **Soundboard** (playing clips into the mic): a different product.
- **Recording the transformed voice to file**: not requested for v1.
- **macOS, Linux, mobile**: Windows only for this effort.
- **Shipping a Voice Converter in v1**: only the seam for one is in scope. When it's revisited, check model licensing first: bundled voice terms, Beatrice v2 redistribution, and the VCTK corpus behind RVC base models. See [Learn how open-source real-time Voice Converters run](004-ai-voice-converters.md).
